3. Database Schema & Data Models

CREATE TABLE patients (
  id SERIAL PRIMARY KEY,
  mrn VARCHAR(50) UNIQUE NOT NULL,
  name VARCHAR(255) NOT NULL,
  age INTEGER NOT NULL,
  gender VARCHAR(20) NOT NULL,
  phone VARCHAR(50) NOT NULL,
  email VARCHAR(255),
  medical_history TEXT,
  allergies TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE consultations (
  id SERIAL PRIMARY KEY,
  patient_id INTEGER REFERENCES patients(id),
  status VARCHAR(50) DEFAULT 'draft',
  consultation_date TIMESTAMP DEFAULT NOW(),
  audio_url TEXT,
  raw_transcript TEXT,
  structured_data JSONB, -- Vitals, Symptoms, Exam Findings
  soap_note JSONB,       -- Subjective, Objective, Assessment, Plan
  icd_codes JSONB,       -- Array<{ code, description, category, confidence, rationale }>
  cpt_codes JSONB,       -- Array<{ code, description, category, rationale }>
  doctor_notes TEXT,
  doctor_name VARCHAR(255) DEFAULT 'Dr. Priya',
  approved_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

4. Core Functional Modules

Universal Multilingual STT

Transcribes doctor-patient dialogue in English, Hindi, Spanish, French, German, Tamil, and Arabic with automatic clinical entity translation.

Real-Time SSE Streaming

Progressively parses vitals, symptoms, physical exam findings, and SOAP notes in real time without blocking UI loaders.

Superbill & Code Exporter

Exports official Superbill PDFs, RFC 4180 CSV spreadsheets, FHIR JSON bundles, and 1-click clipboard formats for hospital EHRs.

Baileys WhatsApp Gateway

Native multi-device WebSocket connection with in-app QR pairing for automated PDF prescription dispatch.

5. API Endpoints Matrix

Method Endpoint Description Payload / Response Format
GET /api/health Health & database connectivity check { status: 'online', database: 'Neon' }
GET /api/patients List all clinic patients Array<Patient>
POST /api/patients Register a new patient { name, age, gender, phone, history }
POST /api/consultations/transcribe Whisper audio transcription FormData (file: Blob) ➔ { text }
POST /api/consultations/process-ai-stream Server-Sent Events streaming AI Stream: event: vitals, event: soap, etc.
POST /api/consultations/:id/approve Physician sign-off & certification { doctorNotes, doctorName, soapNote }
GET /api/whatsapp/qr Fetch live encrypted pairing QR { connected: boolean, qrDataUrl: string }
POST /api/whatsapp/send-prescription Dispatch prescription to patient { phone, patientName, medications, pdfBase64 }
